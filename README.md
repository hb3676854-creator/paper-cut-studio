# 纸间 · 剪纸实验台

支持电脑、安卓和 iPhone 浏览器的互动剪纸应用。选择折法、逐步折叠、画裁剪线、裁剪、展开和保存作品。

闭合线内挖空；可从纸外起笔，纸外线条不显示。支持团花及长方形连续折剪。画笔、橡皮擦、撤销和重做；每个浏览器的草稿独立保存在本机。

## GitHub Pages

将本目录全部文件上传至仓库根目录。在 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。网站使用平台生成的 HTTPS 地址；无需自购域名。

所有资源使用相对路径，支持项目子目录。没有构建步骤，没有数据库，没有外部脚本依赖。无需添加密钥。

分享时使用 Pages 网站地址，不是仓库地址。打开网站中的“分享入口”即可生成二维码。手机建议使用 Safari 或 Chrome 等系统浏览器。国内各运营商的访问效果需实测。
